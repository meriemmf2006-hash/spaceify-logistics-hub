# Spaceify Logistics Hub

Create a modern, ultra-responsive Progressive Web App (PWA) in Arabic (RTL support) for an Algerian sharing-economy logistics and storage platform named "Spaceify" (سبيسفاي).



### 🎨 Brand Identity & Styling:

- App Name: Spaceify (سبيسفاي)

- Slogan: "كل ماهو فارغ رزق ...و كل رحلة تمثل وفرة  ...   

... من المستودع للرحول، والرزق حاضر!"

- Target Audience: Merchants, E-commerce sellers, Appliance/Furniture stores, Heavy Truck Drivers, Local Utility Drivers (DFSK/N300/Master), and Everyday Citizens.

- Theme & Colors: Professional Glassmorphism & Clean UI. Primary palette: Deep Navy Blue (#0F172A), Vivid Logistics Orange (#F97316), Soft Forest Emerald (#10B981) for sustainability, and Slate Grey backgrounds (#F8FAFC).

- Typography: Arabic Modern Sans-Serif (Tajawal or Cairo font).



---



### 🌐 Core Page Structure & Layout Architecture:



#### 1. Header & Navigation (الشريط العلوي المتجاوب):

- Logo: Modern minimalist icon combining a location pin + warehouse box + moving vehicle + Text "Spaceify".

- Nav Links: 

  - الرئيسية (Home)

  - المساحات والتخزين (Spaces & Storage)

  - الرحلات الفارغة (Long-Haul Trucks)

  - النقل المحلي والرحول (Local Delivery)

  
- CTAs: 

  - button [Outline]: "إضافة عرض (مساحة / مركبة)"

  - button [Solid Orange]: "تسجيل الدخول"



#### 2. Hero Section (واجهة الهبوط التفاعلية):

- Hero Headline: "Spaceify: المنصة اللوجستية التشاركية الأولى في الجزائر"

- Subtext: "نوصل البضائع، نملأ الشاحنات الفارغة، ونستغل المساحات المغلقة لخدمة التجار، المحلات، والأفراد."

- Hero Slogan Tag: Custom highlighted pill badge reading: "كل ماهو فارغ رزق... و كل رحلة تمثل وفرة  ...   "

- Interactive Main Search Bar Component (Central Tabs Search Box):

  - Tab 🏢 [تخزين ومساحات]: Inputs for (الولاية، نوع المساحة: مستودع/كراج/غرفة، مدة التأجير: يومي/شهري).

  - Tab 🚛 [شحن بين الولايات - رحلات فارغة]: Inputs for (ولاية الانطلاق ➡️ ولاية الوصول، نوع البضاعة/الحجم).

  - Tab 🛻 [نقل محلي و ترحيل]: Options for (توصيل أثاث/تجهيزات محلات، ترحيل منازل، توصيل سريع) + Location input.

  - Search Button: "ابحث الآن" with magnifying glass icon.



#### 3. Core Modules Grid (الأقسام الرئيسية الـ 3):

Display 3 interactive glassmorphic feature cards with action buttons:

1. Card 1: "🏢 خبي سلعتك (المساحات الثابتة)"

   - Subtitle: كراء واستئجار المستودعات، الكراجات، والمحلات للتخزين المؤقت باليوم أو الشهر.

   - Button: "تصفح المساحات"

2. Card 2: "🚛 رجعة عامرة (الرحلات الفارغة بين الولايات)"

   - Subtitle: استغل رحلات العودة للشاحنات الكبرى لنقل بضائعك بأقل تكلفة وتقليل انبعاثات الكربون.

   - Button: "استكشف الشاحنات العائدة"

3. Card 3: "🛻 نقل وتوصيل (الهاربين & Master)"

   - Subtitle: خدمة التوصيل الفوري لأصحاب محلات الأثاث والتجهيزات ورحول الأفراد بأسعار شفافة.

   - Button: "اطلب مركب نقل"



#### 4. Dedicated B2B Store Partner Module (بوابة محلات الأثاث والتجهيزات):

- Title: "خدمة التوصيل المباشر للمحلات التجارية (B2B2C)"

- Description: "ربط فوري بين محلات الأثاث، الأجهزة الكهرومنزلية، ومواد البناء مع أسطول الهاربين وMaster لتوصيل مشتريات الزبائن فوراً."

- Quick Dispatch Widget Form:

  - Input field: اسم المحل ورقم الزبون.

  - Input field: عنوان التوصيل.

  - Dropdown: نوع المركبة المطلوبة (الهاربين DFSK / N300 / Master / Partner).

  - Action Button: "طلب سائق توصيل فوري" (Triggers simulated Web Push & SMS notification alert).



#### 5. Live Feed & Mock Listings Showcase (نماذج العروض المباشرة):

- A tabbed gallery showing real-time listings:

  - Sample Listing A (Space): "مستودع 120م² مغطى وآمن - الجلفة" (1500 دج/اليوم).

  - Sample Listing B (Truck): "شاحنة 10 طن عائدة من باتنة ⬅️ وهران (متبقي 4 طن)" (تخفيض 40%).

  - Sample Listing C (Local Delivery): "سيارة Master جاهزة لنقل الأثاث والرحول - الجزائر العاصمة".



#### 6. Smart Notification & PWA Installation Callout (قسم التقنية والإشعارات):

- Feature Cards explaining:

  - 🔔 "إشعارات فورية متقدمة (Web Push & SMS & WhatsApp) لتنبيه السائقين والمؤجرين فور توفر طلب قريب."

  - 📱 "تطبيق ويب خفيف (PWA) يعمل مباشرة على المتصفح دون الحاجة لتحميل تطبيقات ثقيلة."



#### 7. Revenue & Sustainability Badges (طبيعة النمط الاجتماعي والاقتصادي):

- Label Badge: "مشروع مبتكر (القرار الوزاري 1275 - Label Projet Innovant)".

- Green Logistics Badge: "نقل أخضر مستدام يقلل انبعاثات ثاني أكسيد الكربون عبر تعبئة الشاحنات الفارغة."



#### 8. Footer (تذييل الصفحة):

- Quick Links, Contact Info, Terms of Service, User Dashboard Links, and Copyrights © Spaceify 2026.
